📌 Project Overview
This project analyzes Blinkit retail sales data using Python to identify sales trends, product performance, and outlet-level insights.
The analysis focuses on different factors such as item type, fat content, outlet size, outlet location, and outlet establishment year.

📊 Dataset
The dataset contains 8,523 records and 12 columns, including information about:
Item Fat Content
Item Identifier
Item Type
Outlet Establishment Year
Outlet Identifier
Outlet Location Type
Outlet Size
Outlet Type
Item Visibility
Item Weight
Sales
Rating

🛠️ Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn

🧹 Data Cleaning
The project includes data cleaning and standardization of inconsistent categorical values.
For example:
LF → Low Fat
low fat → Low Fat
reg → Regular

The project analyzes:

Total Sales by Outlet Establishment Year
Total Sales by Outlet Size
Total Sales by Outlet Location Type
